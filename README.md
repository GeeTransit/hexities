# hexities

Cities on hexagons. Remake of Catan. Work in progress.

## Setup

Get Python 3 and Git. Git clone this repo and cd into the repository.
Make a virtual environment, activate it, and install the required dependencies.

## Deploy

With the virtual environment activated, run this:

```shell
fastapi run server.py
```

When the server is up, go to http://localhost:8000/ to try the game out.
